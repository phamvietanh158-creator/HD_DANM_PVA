ĐỒ ÁN NỀN MÓNG ONLINE — ĐHXD HÀ NỘI
TS. Phạm Việt Anh | v2025
======================================

CÁCH SỬ DỤNG:
1. Giải nén thư mục này vào một nơi trên máy
2. Mở file nen_mong_index.html bằng trình duyệt (Chrome/Edge)
3. Nhập số liệu đề bài → Lưu → Mở từng module theo thứ tự

CẤU TRÚC:
nen_mong_index.html         → Trang chủ — Nhập số liệu, chọn module
module01_phuong_an.html     → Phân tích địa chất & Phương án móng
module02_kiem_tra_nen.html  → Kiểm tra kích thước đáy móng (TTGH1+2)
module03_chieu_cao_cot_thep → Chiều cao móng & Cốt thép móng đơn
module04_ban_ve.html        → Kết luận & Bản vẽ Phần 1 (Móng đơn)
module05_thiet_ke_coc.html  → Thiết kế cọc (SCT 4 PP + Bố trí)
module06_kiem_tra_coc.html  → Kiểm tra cọc (SD + TC + Nhóm cọc)
module07_dai_coc.html       → Thiết kế đài cọc & Kết luận Phần 3

LƯU Ý:
- Tất cả file phải nằm CÙNG THƯ MỤC để link giữa các module hoạt động
- Dữ liệu lưu trong localStorage của trình duyệt (không cần internet sau khi tải về)
- Cơ sở dữ liệu địa chất 112 số hiệu đầy đủ đã nhúng inline trong mỗi module
