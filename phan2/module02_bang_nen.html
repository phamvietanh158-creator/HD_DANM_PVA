2.1 · TTGH1 — Sức Chịu Tải Móng Băng

Terzaghi ξ₁=ξ₂=ξ₃=1 · Chọn b → kiểm tra ptx ≤ [P] · Điều kiện kinh tế

TTGH1
Điểm khác biệt so với móng đơn — Móng băng
Tải trọng phân bố đường: N₀ (kN/m), M₀ (kNm/m) — tính trên 1m dài băng
Áp lực đáy móng: ptx = N₀tc/b + γ̄·hm  ·  pmax,min = ptx ± 6M₀tc/b²
Sức chịu tải Terzaghi: Hệ số hình dạng ξ₁=ξ₂=ξ₃=1 (móng băng l→∞)
Điều kiện kinh tế: ([P]–ptx)/[P] ≤ 10%
Mặt cắt ngang móng băng — áp lực đáy phân bố hình thang · Tính trên 1m dài
Bảng hệ số Terzaghi — Nγ, Nq, Nc · Móng băng ξ₁=ξ₂=ξ₃=1

2.3 · TTGH2 — Kiểm Tra Độ Lún Móng Băng

Cộng lún từng lớp phân tố · Bảng tra Kz · Điều kiện S ≤ [S]

TTGH2
Phương pháp tính lún — Móng băng
Móng băng (l/b→∞) dùng bảng Kz riêng, chỉ 1 cột (không phụ thuộc l/b).
σgl(z) = Kz(z/b) × pgl  ·  Điểm tắt lún: σgl ≤ 0.1·σbt
Độ lún mỗi lớp đất rời (PP2): Si = β·σgl,tb·hi/E₀i  (β=0.8)
Độ lún đất dính (PP1): Si = (e1i–e2i)/(1+e1i)·hi

Nguyên lý đệm cát — Móng băng

Đọc trước
Nguyên lý đệm cát — Móng băng
Thay lớp đất yếu bằng đệm cát đầm chặt. Tải từ móng phân tán theo góc α=30° chỉ theo phương ngang (vì móng băng dài vô tận, chỉ phân tán bề rộng).
Điều kiện: pđáy đệm ≤ [P]TN của lớp đất bên dưới đệm.
Công thức đệm cát — Móng băng (phân tán 1 chiều)
b' = b + 2·hđ·tan30°  (chỉ mở rộng bề rộng, không mở rộng chiều dài)
pđáy đệm = N₀tc/b' + γ̄đệm·hđ + γ̄·hm
Điều kiện: pđáy đệm ≤ [P]TN
tan30° ≈ 0.577  ·  [P]TN tính theo φ, c của lớp đất thiên nhiên dưới đệm
